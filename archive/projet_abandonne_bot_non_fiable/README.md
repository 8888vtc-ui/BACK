# Projet Abandonné : Bot Non Fiable (WildBG)

Ce dossier regroupe l'ancien projet expérimental WildBG (moteur local WASM / Rust / C).

## Raison de l'abandon :
- Moteur non fiable, lenteurs et imprécisions dans les évaluations de jeu.
- Remplacé définitivement par **Open Sage (bgsage-service sur Google Cloud Run)**, offrant la précision grand-maître Snowie 4 Pro / eXtreme Gammon (XG2) avec latence réseau ultra-rapide.
